# Примеры

Рабочие примеры к модулю. Не куски псевдокода: каждый файл запускается и сам
проверяет, что получилось именно обещанное. Разойдётся обещание с результатом —
пример падает с ненулевым кодом возврата, и это видит CI
(`tests/examples_test.php`).

## Что здесь есть

| пример | цель | где применять |
|---|---|---|
| [check.php](check.php) | цикл правки: пометка, зеркало, обновление, возврат — `Scanner` и `ChangeFile` | свой скрипт проверки после обновления, шаг деплоя, агент-сторож |
| [report.php](report.php) | строка отчёта `Report::getRow()` и ссылка в PhpStorm, экранирование | свой отчёт о правках: письмо, виджет, страница |

## Как запускать

Два режима, файлы одни и те же.

**Без портала** — ядро подменяется заглушками из `tests/stub/bitrix.php`,
классы модуля подключаются автозагрузкой из `tests/stub/autoload.php` по тому
же соглашению, что на портале. Так примеры гоняет CI:

```bash
php examples/check.php
```

**На живом Битриксе** — подключается пролог, модуль берётся
`Loader::includeModule('shef.haschangefiles')`, классы находит автозагрузка.
То есть код примера ровно тот, что вы напишете у себя:

```bash
DOCUMENT_ROOT=/var/www/portal php examples/check.php
```

Режим печатается первой строкой: `Цикл правки ядра [портал]`. Если там
`[заглушки]`, а вы ждали портал — не нашёлся
`<DOCUMENT_ROOT>/bitrix/modules/main/include/prolog_before.php`.

**Файлы сайта примеры не трогают** ни в одном режиме: «сайт» с правками —
во временном каталоге системы, и пример убирает его за собой.

Модуль на портале должен быть **установлен**, а не просто распакован: иначе
пример честно скажет `Модуль shef.haschangefiles не установлен` и вернёт 1.

## Как выглядит успешный прогон

```
Цикл правки ядра [портал]

— 1. Правка с пометкой и зеркало
  ok   зеркало нашлось = array (...)
  ok   правка на месте = Shef\Haschangefiles\Main\Status::Ok
  ...

ГОТОВО: check
```

Код возврата `0`. Любая строка `FAIL` означает, что код разошёлся с тем, что
обещает пример: это находка, а не шум. Ни одного `Warning`, `Notice` или
`Deprecated` в выводе быть не должно — обвязка превращает их в исключение.
